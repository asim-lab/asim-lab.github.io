Scholar Insight Pro Privacy Policy

Last updated: August 11, 2026

Scholar Insight Pro is a Chrome extension that enhances public Google Scholar author profiles with research-impact summaries, publication analytics, authorship information, and matched journal metrics and rankings.

Information processed

The extension processes website content that is publicly displayed on Google Scholar author profile pages, such as publication titles, author names, publication venues, years, citation counts, and related publication metadata. This information is used only to provide the extension's research-analysis features.

Local storage

Scholar Insight Pro may store extension settings, user preferences, synchronization status, and cached metric or matching information locally in the browser to improve performance and preserve settings between visits.

Personal and sensitive data

Scholar Insight Pro is not designed to collect passwords, authentication credentials, financial information, health information, private communications, precise location information, or browsing history unrelated to its Google Scholar functionality.

Data sharing and sale

Scholar Insight Pro does not sell user data. User data is not used or transferred for purposes unrelated to the extension's single purpose, and it is not used to determine creditworthiness or for lending purposes.

Permissions

The extension uses browser permissions only as needed to operate its Google Scholar profile analysis, store extension settings and cached information, and provide features such as synchronization and report generation.

Remote code

The extension does not download and execute remote JavaScript or WebAssembly code. Any external information retrieved by the extension is treated as data and is used only for the extension's stated functionality.

Data retention and control

Locally stored extension data can be removed by clearing the extension's stored data or uninstalling the extension. Scholar Insight Pro does not maintain a separate user account system.

Changes to this policy

This policy may be updated when Scholar Insight Pro's functionality or data practices change. The latest version will be published on this page.

Contact

For questions about Scholar Insight Pro or this privacy policy, please use the contact information provided through the developer website.
